Tentang Kami
Apa itu STT Engine?
Platform Speech-to-Text bertenaga AI, dibangun dengan FastAPI + Faster-Whisper

STT Engine adalah platform transkripsi audio-ke-teks berbasis AI yang dibangun menggunakan FastAPI dan model Faster-Whisper (OpenAI Whisper). Dirancang untuk mendukung kebutuhan transkripsi skala kecil hingga enterprise, dengan dukungan Bahasa Indonesia dan Inggris. Platform ini menyediakan REST API, WebSocket streaming real-time, batch processing, dan sistem manajemen user lengkap.

Tier Paket

Transkripsi Real-time

Streaming dari mikrofon via WebSocket, hasil muncul instan tanpa menunggu rekaman selesai. Latensi rendah untuk use-case live caption.

Upload & Batch

Upload file WAV, MP3, M4A, OGG, FLAC, WEBM. Batch hingga 20 file sekaligus dengan antrean async untuk volume besar.

Export Fleksibel

Export hasil ke TXT, SRT (subtitle), dan VTT. Format siap pakai untuk video editor, captioning platform, dan arsip dokumen.

Multi-model Whisper

Pilih dari tiny hingga large-v3-turbo sesuai kebutuhan akurasi vs kecepatan. Mendukung CPU dan GPU (CUDA) seamlessly.
